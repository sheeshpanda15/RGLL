# 模型、计算与待核验项

## 分区更新

三个模型共享 $Y=F\beta+Zu_G+\epsilon$。RI 只使用随机截距，RS 使用随机截距加共同斜率方差的对角 $D$。每次 Gibbs sweep 固定 $\beta,D,\sigma_e^2$ 并积分组随机效应，以组内已有观测构成的联合正态条件预测给当前观测计分。然后从对应全条件依次抽样组随机效应、共同固定效应和方差分量。这里的充分统计量更新通过 Cholesky 初始化和秩一更新维护。遇到不稳定的降秩更新时重建同一全条件并计数。

- DPM 使用 CRP 质量 $n_k$ 和 $\alpha$，并用对数尺度的 Metropolis 更新浓度。DPM 占用组数是分区诊断，普通混合模型中其后验存在估计有限真实分量数不一致的情形。 [Miller 与 Harrison 的一致性结果](https://jmlr.csail.mit.edu/papers/v15/miller14a.html)
- MFM 使用有限支持上的截断几何总分量先验和对称 Dirichlet 权重先验。观测重新分配权重为 $n_k+\gamma$ 和 $\gamma V_n(t+1)/V_n(t)$，其中 $t$ 是暂时移除该观测后占用组数。新协变量预测使用 $V_{n+1}$。从 $K_{\mathrm{total}}\mid G$ 另行抽样总分量数，允许空分量。 [Miller 与 Harrison 的 MFM 分区律](https://pmc.ncbi.nlm.nih.gov/articles/PMC6035010/)
- PPMx 使用 $c(S)=\alpha\Gamma(|S|)$ 和积分掉组均值后的对角正态协变量边际似然 $g(X_S)$。协变量以训练均值和标准差标准化，共享预设组内方差。分区更新把 $g(X_{S\cup\{i\}})/g(X_S)$ 的预测密度乘入各组权重，保留响应似然。`log_cohesion` 和 `log_covariate_similarity` 支持检查 Case 3 的高维干扰结构。 [Müller、Quintana 与 Rosner 的 PPMx](https://pmc.ncbi.nlm.nih.gov/articles/PMC3090756/)

所有先验和采样预算都是首轮试验设置。MFM 的支持上界是截断先验的范围。PPMx 的浓度固定在配置值，DPM 的浓度采样。单点 Gibbs 可能在分区模态之间移动缓慢，当前采样器用多链、两类起点、组数和参数轨迹、经典 split R-hat、近似 ESS 和不同先验变体帮助识别问题。固定组数、训练真值或测试响应均不进入采样器。

## 新样本和 IMSPE

DPM 和 MFM 的随机系数混合仅使用训练响应似然来解释分区。预测时，为每个保存的训练分区计算同一种正则化高斯分配权重。这是**训练后概率门控**。PPMx 使用相同的分配接口，其权重来自分区模型的协变量项。每个 draw 的概率向量末列是新组概率。现有组随机效应在相应 draw 内加权，后验预测同时积分新组的零均值随机效应及其方差。最终跨 draw 汇总预测均值与标准差。

硬预测以抽样样本对的共分组损失选一个代表 draw，在其占用组中按最大概率分配新样本。这是统一的硬分组规则，单独报告新组概率。代表分区在 RGLL 兼容的 ML-EM 实现中重新拟合，用参考协变量硬权重计算全局 plug-in IMSPE。后验条件 IMSPE 对均匀取出的最多 12 个 draw 各用其固定方差分量计算式（10）。Schur 补把固定效应、交叉项和随机效应项写成同一二次型。条件 IMSPE 是工作模型诊断，与包含分组不确定性的后验预测风险分别报告。

## 运行前的验收

已写验收代码覆盖 RI／RS 的式（10）与现有 evaluator 对照、共享随机效应边际似然、MFM 新组概率、PPMx 积分相似性、标签置换、预测数据隔离和断点回放。正式数据继续通过已核对的 RGLL 适配器生成，配置保留 Case 7 的参考和测试目标分布。首轮执行需要核验数值一致性、每链工作集和耗时，以及 80 步预热、每链 60 个保留 draw 是否足够。首先采用 RI 设定。RS 的分区更新复杂度随占用组数及随机效应设计维度的平方增加，耗时和内存尚未实测。
